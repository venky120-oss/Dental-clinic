# Benny Dental Care

One-page website for Benny Dental Care, Karaikudi.

- `benny-dental.html` – the page (content, styles and script)
- `img/` – before/after slider images
- `build.mjs` – builds the deployable site into `dist/` (`node build.mjs`)

Deployed on Vercel, which runs `node build.mjs` and serves `dist/`.
